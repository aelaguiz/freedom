# Codex Dock Live Means Current User Intention

Date: 2026-06-01

## Intention

You want Codex Dock to act like a live view of your real Codex work, not a
separate app that has its own private idea of what happened.

When you are actively working in Codex, the app should show that work. Newest
real activity should be at the top. Opening a thread should show the latest
thread state. If that thread changes while it is open, it should update on its
own.

Filters are allowed to narrow what you asked to see. They are not allowed to
hide current work by default, quietly make new work disappear, or explain stale
data after the fact.

`Live` only means one thing: the visible screen is being kept current against
the real Codex source. If the app cannot prove that, it should say stale,
reconnecting, delayed, failed, or not connected.

Net: if you look at the simulator and do not recognize what it is showing
compared with the Codex work you are doing right now, the system is wrong until
it either catches up or clearly says why it cannot.
