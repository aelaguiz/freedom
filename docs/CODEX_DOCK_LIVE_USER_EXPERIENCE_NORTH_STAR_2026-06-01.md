# Codex Dock Live User Experience North Star

Date: 2026-06-01

## Intention

Codex Dock should feel like a truthful live window into Codex work.

When you open the app, the newest real work should be at the top. When you open
a thread, the thread should keep updating while you are looking at it. The app
should never quietly hide current work behind cache, filters, stale relay state,
or a fake `Live` badge.

Current work should be visible by default. Filters should be explicit user
choices, not explanations for why recent work is missing. If the app cannot
prove it is current, it should say that plainly: stale, reconnecting, delayed,
or failed.

Net: the user should recognize the Codex work they are doing right now. If the
screen does not match reality, the system is wrong until it can either catch up
or clearly explain that it cannot.
